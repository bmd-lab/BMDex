# Datasets

Curated scientific datasets used by BMDex tools, workflows, and examples.

Each canonical dataset should include a `bmdex.yaml` sidecar that records
status, provenance, validation, limitations, and downstream uses.

- `oxidation_states/representative_84/`

Structure-prototype reference material is grouped under
`tools/structure/prototypes/` because it is primarily used as structure
workflow infrastructure rather than as a standalone general-purpose dataset.
