# Crust Abundance Data

Canonical metadata:

- `bmdex.yaml`

This dataset contains the `element-abundances.xlsx` workbook used by the
structure-prototype ranking workflow.

The workbook contains a sheet named:

- `crust abundance`

## Repository Role

This dataset supports abundance-aware compositional ranking and provenance
scripts preserved with the Materials Project unique framework dataset.

## Important Limitations

The original source and units of the workbook should be documented before this
dataset is used as a general lab standard for abundance-based screening.
