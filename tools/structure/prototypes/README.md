# Structure Prototypes

This directory groups structure-prototype-related reference material with the
rest of the structure toolkit in BMDex.

Included here:

- `bmdex.yaml` canonical BMDex metadata for the imported prototype collection

Raw source data remains external:

- `external/structure-prototypes/`

The external repository contains the CIF collection and generated prototype
summaries. This directory provides the local integration point and metadata
layer without duplicating those files into the main repository tree.
