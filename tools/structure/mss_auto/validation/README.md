# MSS-Auto Validation

This directory contains validation workflows and reference structures for MSS-Auto.

Validation goals include:
- reproducible slab generation
- preservation of crystallographic orientation
- correct vacuum insertion
- physically meaningful slab structures
- compatibility with VASP workflows

## Validation Philosophy

Validation should prioritize:
- reproducibility
- structural consistency
- maintainability
- and transparency of assumptions.

Validation does not guarantee:
- thermodynamic stability
- experimental synthesizability
- or exfoliation feasibility.

## Recommended Validation Checks

Generated structures should be checked for:
- overlapping atoms
- sufficient vacuum spacing
- expected orientation
- stoichiometric consistency
- symmetry preservation where appropriate

## Suggested Reference Systems

Representative validation systems may include:
- MoS2
- graphite
- layered oxides
- representative perovskites
- known nonlayered materials
