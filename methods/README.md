# Methods

Method notes, standards, and scientific conventions used across BMDex.

This section should be organized by scientific topic and workflow domain rather
than by software brand alone. Framework-specific guidance belongs here when it
clarifies how the lab uses a tool within a broader materials-science task.

Current entries include:

- `repository-access-model.md` staged access and execution model for tutorials, GitHub, cluster checkouts, and Codex
- `vasp/` VASP input standards and calculation conventions
- `structure-manipulation/` structure workflow philosophy
- `repository-governance/` repository organization, metadata, and historical design records
