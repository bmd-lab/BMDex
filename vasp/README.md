# VASP

This section contains lab-wide VASP calculation standards and conventions.

It is separate from:

- `hpc/vasp/`, which records cluster-specific VASP execution guidance,
  templates, and runnable examples
- `tools/vasp/`, which contains directly runnable VASP utility scripts

## Contents

- `input-standards.md`: BMD Lab conventions for VASP inputs,
  pseudopotential handling, convergence expectations, and documentation
  of calculation assumptions
