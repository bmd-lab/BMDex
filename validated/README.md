# Validated Status Index

Validation status is now recorded in canonical `bmdex.yaml` sidecars. This
directory is retained as a status-oriented index and compatibility layer during
incremental migration.

Validated content should:
- contain sufficient documentation
- specify assumptions explicitly
- include expected inputs and outputs
- avoid undocumented dependencies
- be reproducible within the group computational environment

Validated status does not imply universal applicability. Scientific judgment and system-specific validation remain necessary.
